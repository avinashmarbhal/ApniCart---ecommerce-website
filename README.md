# 📦 ApniCart – E-Commerce Web Application

**ApniCart** is a full-stack e-commerce web application built with the MERN stack, designed for shopping, selling products, and managing user accounts. It combines a responsive frontend, secure backend, and scalable state management to deliver a seamless user experience.

**🌐 Live Demo:** [https://apnicart.netlify.app](https://apnicart.netlify.app)  
*Note: The initial load of the website may take up to a minute due to server cold starts or free-tier hosting limitations.*

---

## 🔹 Features

- **User Authentication & Authorization:** Secure login and registration using JWT and custom middleware.  
- **Role-Based Access:** Protected routes with full access control for Users, Sellers, and Admins.  
- **Product Management:** Users can browse and search products; sellers can add, update, and remove listings.  
- **Shopping & Checkout:** Add to cart, manage quantities, and complete orders seamlessly.  
- **Email Notifications:** NodeMailer integration for account creation, OTP verification, and seller request updates.  
- **Cloud Storage:** Product images hosted on Cloudinary for secure and efficient delivery.  
- **State Management:** Redux ensures scalable and efficient state handling.  
- **Responsive UI:** Dynamic frontend built with reusable React components for maintainability.  
- **Database:** Cloud-hosted MongoDB Atlas for reliable data storage.  
- **Hosting:** Backend hosted on **Render**, frontend hosted on **Netlify** for high availability.

---

## 🔹 Tech Stack

- **Frontend:** React, Redux, Tailwind CSS, JavaScript  
- **Backend:** Node.js, Express  
- **Database:** MongoDB Atlas  
- **Cloud Services:** Cloudinary  
- **Email:** NodeMailer  
- **Hosting:** Render (backend), Netlify (frontend)
